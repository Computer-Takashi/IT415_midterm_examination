# IT415 Touchscreen POS Kiosk

Campus food outlet kiosk for the IT415 practical examination.

## Development plan

1. Set up a dependency-free HTML, CSS and JavaScript project.
2. Build the touchscreen catalog and cart.
3. Add review, simulated cash/QR/card payments, receipts and reset.
4. Test validation, calculations and navigation, then document acceptance evidence.

All payments are simulations. Transaction state is kept in memory.

The Sample UI and original acceptance checklist were referenced but not supplied.

Implementation is in progress.
